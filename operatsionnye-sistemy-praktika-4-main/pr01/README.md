# ПР-1. Диагностическое тестирование и терминал Linux

## Цель

Развернуть Linux/WSL2, проверить терминал, команды, структуру каталогов и базовые права доступа.

## Команды

```bash
whoami
pwd
uname -a
lsb_release -a
mkdir -p ~/os-course/pr01
cd ~/os-course/pr01
echo "Практическая работа №1" > about.txt
echo "Знакомство с терминалом Linux" >> about.txt
cat about.txt
ls -la
```

## Пример результата

- `whoami` показывает имя текущего пользователя.
- `pwd` показывает текущий каталог.
- `uname -a` показывает ядро Linux и архитектуру.
- `lsb_release -a` показывает версию дистрибутива.

## Объяснение `ls -la`

Для строки файла `about.txt`:

- первый столбец — тип файла и права доступа;
- второй — количество жёстких ссылок;
- третий — владелец;
- четвертый — группа;
- пятый — размер в байтах;
- далее дата и время изменения;
- последний столбец — имя файла.

## Вывод

Среда подготовлена, базовые команды терминала работают, файл создан и читается.
