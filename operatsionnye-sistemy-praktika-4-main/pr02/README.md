# ПР-2. Bash и системные вызовы

## Цель

Освоить bash-скрипты и увидеть системные вызовы через `strace`.

## Запуск

```bash
chmod +x report.sh
./report.sh data ERROR
./report.sh --top 3 data WARN
python3 hello.py data/01.log
strace -c ls
strace -c cat data/01.log
strace -f -o trace.txt python3 hello.py data/01.log
strace -e trace=openat cat data/01.log
```

## Что делает `report.sh`

Скрипт принимает каталог и уровень журнала (`ERROR`, `WARN`, `INFO`), затем выводит таблицу:

```text
module count
```

Сортировка выполняется по убыванию количества сообщений.

## Выводы по `strace`

Частые системные вызовы:

- `openat` — открытие файлов и библиотек;
- `read` — чтение данных из файла;
- `write` — вывод данных в терминал;
- `close` — закрытие файлового дескриптора;
- `mmap` — отображение файлов и библиотек в память.

`cat` открывает библиотеки до пользовательского файла, потому что динамический загрузчик сначала подготавливает окружение программы и подключает libc.

## Ответы на контрольные вопросы

Пользовательская программа не обращается к диску напрямую, потому что доступ к устройствам контролирует ядро ОС. Это защищает систему и данные других процессов.

Системный вызов дороже обычной функции, потому что требует перехода из пользовательского режима в режим ядра и обратно.
