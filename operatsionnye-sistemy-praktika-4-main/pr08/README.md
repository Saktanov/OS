# ПР-8. Взаимоблокировки

## Цель

Воспроизвести deadlock, исправить его, реализовать алгоритм банкира и детектор ожидания.

## Запуск

```bash
python3 deadlock.py
python3 deadlock_fixed.py
python3 banker.py bank1.txt
python3 banker.py bank2.txt
python3 banker.py bank1.txt --request P1 1 0 2
python3 tracked_lock.py
python3 philosophers.py
```

## Вывод

Deadlock возникает при выполнении четырёх условий: взаимное исключение, удержание и ожидание, отсутствие принудительного отбора, циклическое ожидание. В `deadlock_fixed.py` нарушено циклическое ожидание: все потоки захватывают блокировки в одном порядке.

Для `bank1.txt` состояние безопасное, для `bank2.txt` — небезопасное. Алгоритм банкира редко используется в универсальных ОС, потому что требует заранее знать максимальные потребности процессов.
