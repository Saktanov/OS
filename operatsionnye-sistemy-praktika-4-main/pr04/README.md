# ПР-4. Потоки

## Цель

Создать потоки, сравнить потоки и процессы, объяснить влияние GIL.

## Запуск

```bash
python3 threads_demo.py
cat /proc/$$/status | grep Threads
ls /proc/$$/task

python3 gen_numbers.py
python3 sum_benchmark.py
python3 memory_share_demo.py
python3 io_benchmark.py
```

## Выводы

- Потоки одного процесса разделяют память, поэтому общий список меняется после работы потока.
- Процессы имеют отдельную память, поэтому изменение списка в дочернем процессе не видно родителю.
- В CPython GIL мешает ускорять CPU-bound задачи потоками.
- Для I/O-bound задач потоки помогают, потому что во время ожидания сети другой поток может выполняться.
- Процессы ускоряют CPU-bound задачи, но создание и обмен данными дороже.
