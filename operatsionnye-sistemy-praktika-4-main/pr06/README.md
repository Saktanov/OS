# ПР-6. Синхронизация

## Цель

Устранить гонки и применить мьютексы, семафоры и условные переменные.

## Запуск

```bash
python3 race.py
python3 race_fixed.py
python3 bank.py
python3 producer_consumer_semaphore.py
python3 producer_consumer_condition.py
python3 barrier_demo.py
```

## Вывод

`Lock` защищает критическую секцию и делает результат корректным, но добавляет накладные расходы. Семафоры удобно использовать для подсчёта свободных и занятых ячеек буфера. Условная переменная всегда используется вместе с мьютексом и проверкой условия в цикле `while`.
